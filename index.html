Configuración inicial · Solo se hace una vez

📋 Cómo conectar tu base de datos:

  1. Ve a supabase.com → "Start your project" → entra con Google o GitHub
  2. Crea un nuevo proyecto (nombre: vigias, región: South America)
  3. Espera ~2 minutos a que se cree
  4. Ve a Settings → API
  5. Copia la Project URL y la anon public key y pégalas abajo
  6. Ve a SQL Editor y ejecuta el SQL que te envié aparte
Ejemplo: https://abcdefghijkl.supabase.co
La clave pública (anon public) — no la service role key
